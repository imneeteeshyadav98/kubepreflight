Result -- the complete, exact set of AWS API calls made anywhere in the AWS

and ListUpdates check the status of any EKS update already in progress (e.g. one

approves, or modifies an update. No mutating AWS API (e.g. UpdateClusterVersion,
UpdateNodegroupVersion, StartUpdate, CreateCluster, DeleteCluster) appears
anywhere in production source.
